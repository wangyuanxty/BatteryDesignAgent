让 Agent 自己设计电池

An Autonomous End-to-End Agent for Battery Cell Design with Verifiable Outcomes
一句话输入——"设计一块能量密度 ≥ 392.61 Wh/kg、4C 快充不析锂、最高温度 ≤ 60 ℃ 的轿车电池"——它自己走完分子筛选 → 电极结构 → 电芯仿真 → 安全验证 → 真 DFT/MD，交出一块完整的电芯设计。

8 个场景任务 轿车 · 储能 · 电动工具 · 极寒 · 旗舰 · 手机 · 混动 · 无人机 主模型全部达标 3 seeds 复现 24/24 同类方法对比 贝叶斯优化 3/8 · 不按流程的 agent 0/7

01 · 出发点

电池设计要在五个互相牵制的层上同时定方案，而每验一次都很贵

  • 五层互相牵制——材料体系、电解液配方、电极结构（颗粒半径／孔隙率／厚度）、电芯架构、热管理；单独把哪一层调到最好，都可能让整芯更差；
  • 验证代价高——寿命评估动辄数千小时连续充放；固/液相输运系数、反应速率常数这些关键微观参数测不到，只能由宏观电压／容量轨迹反推（教科书级的逆问题）；
  • 现有自动化各做一段——贝叶斯优化只调结构参数、自主实验室只做合成闭环、LLM 化学家只做分子任务；没有谁在一条闭环里跑完整条链（从电解液到热集成）。
于是我们问两个问题：一个 LLM agent 能不能把整条链自己跑完？它报出来的结果，能不能核？

02 · 研究现状

五条路线，各自留下的空缺

路线代表工作空缺
经典优化与代理模型贝叶斯优化／高斯过程（含电池设计专用 BO）搜索空间是列好的参数；换体系、改化学这类杠杆不在其空间内
分子／材料筛选高通量筛选、ML 势（MACE／CHGNet）、半经验量子（xTB）单点预测；没有跨尺度闭环，不回答"装进电芯行不行"
LLM 用于科学发现ChemCrow、Coscientist、A-Lab 等自主实验系统多为"工具调用＋文献问答"，判据由模型自选，结论无法按规则复核
电池专用 agentBattery-Sim-Agent 等（以 BO 为标准配置）以结构参数为主；材料级杠杆缺席
工程实践／可验证性跑前定好判据、审计链、按规则核对在科学 agent 里尚未成为默认；多数工作把"模型自报的达标"当成结论

02 · 文献留下的空缺

两件没人做过的事 —— 也就是本文要回答的问题

空缺 1

整条链没人跑完

材料发现停在做材料、电路自动化停在电路、参数反演停在参数；没有谁把从电解液到热集成的整条链放进一条自主闭环。

空缺 2

没有一套考"整条链"的任务

已有工作的评测都落在链的一段：曲线拟合误差、分子性质、合成的配方。没有任务集要求 agent 交出一份完整电芯设计，并同时满足容量、4C 不析锂、温度、SEI、质量这些绝对判据。我们的 8 个场景任务就是填这个坑：3 个瓶颈在结构、5 个要靠材料，让对比能真的判别出东西。

三个研究问题：①固定流程能不能提高达标率，代价多少？ ②流程里哪条规则真在起作用？ ③按规则核对，接得住"自己改判据"吗？

03 · 方法

流程：五阶段漏斗 + 五条常开规则

Stage 1–2

规划 → 分子筛选

先出方案（目标分解、候选策略、预算、风险），再做材料级筛选：三个模型异质投票（MACE／CHGNet／xTB）。

Stage 3–4

电芯设计 → 安全评估

SPMe 速筛 → DFN 精算；4C/45 °C 耦合热 + 析锂判定，安全是独立的目标维度。

Stage 5

真计算背书

只给决赛圈：两套独立 DFT（ORCA r2SCAN-3c／CP2K PBE-D3）＋真 MD 扩散。

Governance

五条规则常开

回退路由、天花板评估（达到上限才触发换体系）、多模型投票、按规则核对、审计链拒绝。

03 · 方法

一条闭环：设计目标进来，核对写在外面

  • IN
    自然语言设计目标（唯一输入）

    目标与阈值原文即判据；agent 不得重新锚定、重新校准或重新诠释。

  • LOOP
    每轮：提出 → 筛选 → 仿真

    失败被诊断到原因所在的尺度再退回；当前体系被证明达不到时，才升级到换体系。

  • TOOL
    命令行工具库 bda

    电芯／分子／量子／热失控／能量密度口径——全部由流程规定，agent 只调用、不改造。

  • JUDGE
    核对程序（代码，在 agent 之外）

    读第 0 条判据与仿真输出，按规则核对；证据链缺项即拒绝，不允许"口头结论"。

  • LEDGER
    审计账本 log.jsonl

    逐轮留痕：候选、理由、输出、核对结果、证据。论文每个数字都能从账本重放。

04 · 实验设计

8 个场景任务 × 三种做法，条件相同

  • 任务：8 个场景（快充车／电网储能／电动工具／极寒设备／旗舰车／手机／混动／长航时无人机），判据全是绝对数值。
  • 三种做法：按流程的 agent／不按流程的 agent（同 harness、同预算、同通用仿真栈，prompt 里写明可用库与入口 API）／贝叶斯优化（复刻已发表的 BO 标准配置，50 次评估）。
  • 同预算：agent 侧统一 300 轮上限；BO 侧固定 50 次评估——用轮次／消息／token 同口径记录，不用美元口径比较。
  • 重复：主模型 3 seeds（24/24）；另有两个外部厂商模型各 8 跑（模型鲁棒性）。

04 · 实验设计

"达标"怎么判：判据分层 + 代码判定

层内容谁判
stage1分子级目标与淘汰线（稳定性上限、氧化稳定性上限）漏斗规则
stage2电芯性能（容量 / 能量密度，统一口径 calc-energy）按规则核对
stage3安全（最高温度、是否析锂——由负极电位时序自动推导）按规则核对
meta轮次预算、真计算开关等案例级参数第 0 条落盘
判据在第 0 条落盘后即固定：跑完不许改阈值（结果不利时放宽判据＝作弊）。核对命令 bda log-evaluate 由代码生成结论与证据，agent 不得手写。

05 · 结果 ①

主对比：按流程 8/8，另两种做法各 3/8

做法达标说明
按流程的 agent（主模型）8 / 8两个 DeepSeek 世代模型各自 8/8；主模型三 seed 复现 24/24
按流程的 agent（其他模型）4 / 8GPT-5.6 Luna 与 mimo-v2.5 各 4/8，经 OpenAI 兼容 API 接入——如实报告模型依赖
贝叶斯优化3 / 8恰好是瓶颈在结构的那三个；材料瓶颈的五个全部卡死
不按流程的 agent（批内）0 / 7结论全部经统一口径复判；该批工具不对称已披露（见 Q&A）
两种做法的失败互不重叠：BO 缺杠杆、不按流程的 agent 缺外部判定、按流程时两者都有——这正是论文的核心观察。

05 · 结果 ②

测量漂移：不按流程时，agent 会自己把标准调松

模式实测
自设阈值"−6.9 mV 也算安全"（目标是零容忍；它自设析锂起点 −10 mV）
替换模型SEI 生长律换成溶剂扩散限制模型（目标口径是 ec 反应限制）→ 复判后 818.9 nm（限 550）
换口径"96.7% 保持率"在 C/3 下测（目标是 5C/1C）；且自设扩散系数为标准值 2.5×
缺判据变量只给热点温度、不给触发判据；或干脆没有负极电位时序
离开测量空间换到锂金属体系（不在已验证参数集内）——"达标"但不计入
所以本文的对照不是"裸 agent 不行"，而是：没有外部核对时，"达标"这件事本身不可判定。

05 · 结果 ③

消融：哪条流程规则真的在起作用

天花板评估

对 2/3 材料瓶颈任务因果

关掉"当前体系不可达才升级材料搜索"，这些任务直接失败——它是材料杠杆的触发器。

强制结构探索

对 1/6 任务因果

多数任务不强制探索也能找到结构解；影响面小于预期，如实报告。

三模型投票

被触发但从未改变结论

本套任务里没有出现"分歧决定胜负"的案例；作为零结果如实记录。

另有模型鲁棒性（4 个模型家族、3 个 harness 可移植）与仿真器锚定：商用 LG M50T 实测与参数集吻合到 0.45% 容量 / 20.6 mV RMSE。

05 · 结果 ④

真计算背书：结论级数字不由代理模型签字

  • 两套独立 DFT 交叉验证（ORCA r2SCAN-3c ＋ CP2K PBE-D3）：旗舰案例的决赛分子在两个独立程序里结论一致。
  • 真 MD：经典力场跑 1 ns，报告 Li⁺ 扩散系数 D_Li = 5.4×10⁻¹¹ m²/s——"结论级"数值，代理模型不参与签字。
  • 成本纪律：真计算只给 Top-N 收尾；漏斗内禁止调用（毫秒级代理负责淘汰，小时级真计算负责背书）。
除了这三层流程，还有一层：交付数字的证据等级是分层的——论文里每个数都标了来源（工具直接值／由工具值推算／领域估计）。

05 · 结果 ⑤

把目标设到文献之外：两条强制任务

添加剂侧

72 候选 → TFAA

目标 SEI ≤370 nm，而文献里最好的添加剂只到 385 nm。agent 交出三氟乙酸酐：不在已知集、不属于任何已筛化学族，且比电解液自身溶剂更先被还原——能成膜的前提。电芯：SEI 322.6 nm / 400.29 Wh/kg / 无热失控。

电极侧

42 候选 → 负结果

窗 4.6 V，且必须与固定碳酸酯电解液相容。唯一过电压窗的候选（4.641 V）充电要 7.41 V，超电解液极限 2.6 V → 它自己算出来后如实判负，并指出机理：氧参与氧化还原的层状路线走不通。

两件事都写进论文：它能在给定体系之外做设计，也不把"看着达标"当成达标。

06 · 预备问答（上）

"不按流程的 agent 不给 CLI 工具"，这样比公平吗？

差的是流程自带的那套工具，不是能力。两侧跑在同一个环境克隆上（同库同版本、同 CUDA），且裸版 prompt 里写明了可用库与主要入口 API；按流程时多的是一套编码了测量口径的命令（命名老化流程、统一口径的能量密度、按规则核对）。更早那批连通用库与环境说明都没有——论文已如实披露其工具不对称，并把该批一并报告，不作为同工具对比。

为什么判据用 HOMO 这种代理量？

因为在这套实验里它有明确物理含义：HOMO 深度经固定公式映射到 SEI 生长速率 k，是可复算、无自由参数的映射。但它也暴露了判据的通病——判据测什么，就只会得到什么：只要求"HOMO 越深越好"时，agent 交回的是惰性全氟分子（根本不会成膜）；加上"必须比溶剂先被还原"之后，答案才落到真能起作用的化学上。

为什么贝叶斯优化只有 3/8？

它的搜索空间是十个结构参数，没有分子／材料杠杆。三个结构性瓶颈任务它能达标（厚度、孔隙率、质量），五个材料瓶颈任务它连"候选"都给不出——这不是调参问题，是空间之外。它的最优解甚至违反目标的约束判据（SEI 559.2 nm vs 370 nm）。

06 · 预备问答（下）

那算"发明了新材料／新分子"吗？

不算，论文也没这么主张。TFAA 是已编目的化合物、且属文献已知的酸酐类添加剂；电极侧的候选也已在 Materials Project 有计算条目。我们的判据能证明的是"不在我们给定的集合里"，证明不了"文献里没有"——离开给定集合 ≠ 离开文献，这两件事在论文里分开写。

预算真的对齐吗？

agent 侧统一 300 轮上限（轮次按 SDK 定义：一次"用户侧输入→响应"往返为一轮）；BO 侧固定 50 次评估。成本口径用轮次／消息／token，不用美元（不同模型渠道单价不同，不可比）。外部厂商模型 4/8 的降级已如实写入正文。

T9 为什么收在负结果？

因为"可用"这条线只能这么画：5.3 V 窗配上固定的碳酸酯电解液（阳极极限约 4.8 V）物理上就装不进这颗电芯；把窗口挪到电解液撑得住的 4.6 V 之后，六个可算族里没有解——唯一过电压窗的候选充电要 7.41 V。与其交一个"通过但用不了"的答案，不如如实报负。
