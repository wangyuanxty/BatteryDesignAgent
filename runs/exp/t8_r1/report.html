mass_scalingCell mass scales linearly with electrode area at fixed stack; ED, 5C retention and T_max are area-invariant (lumped thermal mass scales with Cell volume). Design rounds run at native geometry (0.065 x 1.58 m; Chen2020 default stack 0.4231 kg/m2 -> native mass 43.45 g, probed). Closing round scales area jointly (Electrode height/width, Cell volume [m3], Cell cooling surface area [m2], Nominal cell capacity [A.h]) by f = 0.04 / native_mass_kg and re-verifies mass_kg <= 0.04 on fresh runs. Intermediate rounds may therefore show mass_kg unchecked.
base_defaultTask text names no electrode system -> protocol default Chen2020 (recorded). Discriminant anchor verified by dumping the set: NMC811/graphite teaching parameterization, no SiOx in negative electrode (density 1657 kg/m3, no cracking-rate keys), aging-capable (SEI kinetic rate constant [m.s-1] = 1e-12), full geometry present (Electrode height 0.065 m, width 1.58 m, Cell volume 2.42e-5 m3, nominal capacity 5 Ah).
excluded_leversSolid-phase conductivity/solid-phase diffusivity (no formulation/doping mapping model), initial concentration/lithiation (breaks baseline comparability), Initial SEI thickness (calibration constant), charge cut-off voltage (usage mode) — per protocol, forbidden as design levers.
cycle_life_noteTask text contains no cycle-life metric -> aging protocol not required by criteria; Chen2020 is aging-capable if a coating/doping candidate later requires it.
