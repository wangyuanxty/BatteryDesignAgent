SEI@500 root cause = baseline SEI kinetics: SEI kinetic rate constant x0.2 (1e-12->2e-13 m/s) as coating-suppression bridge (Al2O3-class coating). All overrides listed before running per protocol. Sources: particle radii/SEI kinetics = estimate (domain, bridge values); sigma 1.5 S/m (15 mS/cm) and t+ 0.45 = literature-order values for advanced LiFSI-based/high-transport electrolytes, marked estimate; baseline values measured from Chen2020 set (sigma(1000)=0.949 S/m, t+=0.2594).
