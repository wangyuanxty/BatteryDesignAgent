# 电池设计：指标、步骤、仿真与对应关系

本文整理电池电芯设计的领域结构，用于架构设计与任务划分。四部分：性能指标、设计步骤、仿真方法、对应关系。最后给出四条观察。

一项指标最好能做到多少、能不能事先算出来，分三种情况，原因完全不同：

- **能算**：由物理或材料常数给出，不随设计变化，可以据此判定"够不够得着"
- **不能算——没有可用的理论**：只有经验关系（如界面化学）
- **不能算——隔着工艺**：从设定的量到仿真参数，中间有一段既控制不了也算不出的过程（如工艺造成的微结构）

## 二、设计步骤

按实际设计流程的顺序。

| # | 步骤 | 主要变量 |
|---|---|---|
| 1 | **定场景与指标** | 应用场景决定哪些指标是硬约束 |
| 2 | **选化学体系** | 正极（NMC / LFP / LMO）、负极（石墨 / Si / SiOx / 锂金属）、电解液大类 |
| 3 | **定电极配方与修饰** | 活性物质 / 导电剂 / 粘结剂比例、颗粒半径分布；包覆 / 掺杂（作用在界面，改 SEI 动力学或开裂速率） |
| 4 | **定电芯结构** | 电极厚度、孔隙率、N/P 比、隔膜、集流体 |
| 5 | **定热管理** | 冷却设计（冷却板、流道、流速）、电芯尺寸 |
| 6 | **定电解液配方** | 溶剂比、盐（LiPF₆ / LiFSI）、添加剂（成膜 / 阻燃 / 过充保护） |
| 7 | **定工艺** | 化成制度、注液量、压实 |

**第 2 步与第 6 步要分开看**：化学体系决定**能量上限**，电解液配方决定**界面行为**。两者影响的指标几乎不重叠，是两条不同的路。

### 关于"选"与"造"的边界

本图覆盖的是**从已有里选**：化学体系从已验证的参数集里选，添加剂与包覆/掺杂材料从已有化合物目录里选。

**不覆盖"设计新分子并合成"那一段**，两个原因：

| 原因 | 说明 |
|---|---|
| **仿真给不出功能** | 分子性质（还原电位、HOMO/LUMO、结合能）能算，但从性质到电池性能（SEI 质量、界面动力学 $k$）这条链接没有理论，只能靠经验关系 |
| **合成与实测在边界外** | 设计出的分子要合成、要实测才作数，两步都需要湿实验；周期以年计，与仿真循环差几个数量级 |

**这不是取舍，是领域本身的分工**：新分子通常由化工 / 材料公司设计合成，电解液厂商配成电解液，电池厂做的是**选型、配方与结构**。本图覆盖的正是后一段。

## 三、仿真方法

按物理尺度排列。

| 尺度 | 方法 | 算什么 | 代价 |
|---|---|---|---|
| 分子 | DFT（ORCA / CP2K） | 轨道能级、氧化还原电位、反应路径 | 小时–天 |
| | 半经验（xTB） | HOMO / LUMO 快速估计 | 秒 |
| | MD | 扩散系数、电导率、迁移数、溶剂化结构 | 小时 |
| 晶体 | 周期 DFT（QE） | 晶格常数、形成能、**OCP 电压平台** | 小时 |
| | ML 势（MACE / CHGNet） | 结构弛豫、稳定性排序 | 毫秒–秒 |
| 电极 | SPM / SPMe | 固相扩散、简化极化 | 秒 |
| | P2D / DFN | 全阶、空间分辨 | 分钟 |
| | DFN + 老化 | SEI 生长、颗粒开裂、容量衰减 | 分钟 |
| 电芯 | DFN + 热耦合 | 温度分布、$T_{\max}$ | 分钟 |
| | 热失控 ODE | 触发判据 | 秒 |
| | 机械–热耦合 | 针刺 / 挤压 | 分钟–小时 |
| 系统 | CFD | 电池包级热管理 | 小时 |

**电极与电芯两行由 PyBaMM 提供**（SPM / SPMe / P2D / DFN、老化、热耦合都在里面）；分子与晶体两行由 xTB / DFT / MD / ML 势提供。**下面说的"仿真器"、参数表，指的就是这两组里的对应工具。**

**特征时间**（典型数量级，实际值须按所选参数集计算）：

- 固相扩散：$\tau_s = R^2/D_s \sim$ 10³ s（$R=5\,\mu$m，$D_s=10^{-14}$ m²/s）
- 电解液输运：$\tau_e = L^2/D_e^{\rm eff} \sim$ 10² s（$L=100\,\mu$m，$D_e^{\rm eff}\sim3\times10^{-11}$ m²/s）

两者与 1C 放电（3600 s）同量级，这是倍率性能受扩散限制的直接原因。

## 四、对应关系

### 指标由什么决定

| 指标 | 由哪一层决定 | 用什么仿真 | 最好能到多少，依据是什么 |
|---|---|---|---|
| **比能量 Wh/kg** | 化学体系 × 结构 | 分母（质量）纯代数；分子要**一次 1C 放电**（秒级） | 材料常数给出（理论容量 × 电压），但松 |
| **能量密度 Wh/L** | 同上 | 同上 | 材料常数给出，松 |
| **平均 / 平台电压** | 正极材料 | 周期 DFT，或参数集 OCP 数据 | 材料本身，就是那个数 |
| **比容量** | 材料理论值 × 利用率 | DFN | 上限由材料给出；利用率靠设计 |
| **倍率保持** | 固相扩散 ＋ 电解液输运 | **DFN**（SPMe 在 5C 严重低估容量） | 球扩散利用率有解析式，可用 |
| **低温保持** | 电解液电导率的温度依赖、界面阻抗 | DFN（带温度依赖参数） | Arrhenius 关系，参数集内可用 |
| **DCR / 比功率** | 厚度、孔隙率、电导率 | 从放电起始压降算 | 只有量级，不紧 |
| **循环寿命** | SEI 生长、开裂、锂库存损失 | DFN + 老化模型 | 各机理贡献怎么分摊，没有第一性原理 |
| **SEI 厚度** | 界面动力学 $k$、温度、时间 | 老化模型 | 包覆能把 $k$ 压到多少，算不出来 |
| **析锂** | 负极电位 ＝ 平衡电位 ＋ 过电位 | DFN，读 $\phi_a(t)$ 时序 | 传质极限电流给出 |
| **$T_{\max}$** | 产热（I²R ＋ 熵热）vs 散热 $hA$ | 电化学–热耦合 | 能量守恒给出 |
| **热失控触发** | 放热反应动力学、散热、尺寸 | 三副反应 ODE / Semenov | 判据形式是经典的；数值靠 ARC 拟合 |
| **针刺通过性** | 同上 ＋ 机械侵入 | 机械–热耦合 | 同上 |
| **N/P 比** | 纯设计选择 | 不用仿真 | 是约束，不是指标 |

### 指标不达标时往哪走

**第一步不是动手改，是先问：当前体系的天花板够不够得着？**

够不着 → 直接换体系，别在结构上浪费时间。够得着 → 才按成本从低到高调。

| 指标 | 有天花板可查吗 | 够不着 → | 够得着 → |
|---|---|---|---|
| **电压平台** | 有——就是材料 OCP | **换体系（第 2 步）**，没有别的路 | —— |
| **能量密度** | 有——理论容量 × 电压 | **换体系（第 2 步）** | 结构（第 4 步）→ 配方（第 3 步） |
| **倍率 / 低温** | 有——扩散时间极限 | 换体系（第 2 步）或电解液（第 6 步） | 结构（第 4 步）→ 配方（第 3 步） |
| **析锂** | 有——传质极限电流 | 换体系（第 2 步）或电解液（第 6 步） | 结构（第 4 步）→ 配方（第 3 步） |
| **$T_{\max}$** | 有——能量守恒（这个界松） | 换体系（选产热更低的化学） | 热管理（第 5 步）→ 结构（第 4 步） |
| **SEI 厚度** | **没有** | —— | 电极修饰（第 3 步）· 电解液（第 6 步） |

三件事一眼可见：

**一、电压平台最干脆**——天花板就是材料本身，够不着只能换体系，没有第二条路。
**二、SEI 是唯一没有天花板的指标**——所以它是唯一"只能试"的，与第五节第 3 条"界在体相 / 界面处分界"是同一件事。
**三、天花板够得着时，才轮到成本顺序**——结构最便宜（只是改数），配方与修饰要换材料，电解液要跑 MD。

**这个顺序不能写死**：要是按"先榨结构，再换体系"办，那么在**要求已超过当前材料上限**的指标上（电压平台超过正极 OCP、能量密度超过理论容量 × 电压所能给的），会在结构上白折腾一轮——必须**先判天花板，再决定动手顺序**。

## 五、四条观察

### 1. 能量密度要一次仿真，只有质量和 N/P 比是纯代数

$$E = \frac{\int_0^{t_d} V(t)\,I\,dt}{\sum_i l_i(1-\varepsilon_i)\rho_i A}$$

| | 怎么来 |
|---|---|
| **分母**（质量）＝ 层厚 × 密度 × 面积 | 纯代数——设计变量与材料常数的直接组合 |
| **分子**（放电能量）＝ $\int V(t)I\,dt$ | **要电压曲线 → 要一次 1C 放电仿真**（秒级） |

所以能量密度比老化、析锂那些便宜得多，但**不是"完全不用仿真"**。可以用"理论容量 × 平均电压"估一个上界——那是纯代数，但**是上界，不是实际值**。

**真正纯代数的只有质量、N/P 比这类**（层厚 × 密度、容量比），它们不是微分方程的解。

### 2. 用什么模型，由要算什么指标决定

- 平台电压：只需要一个静态 OCP 值（一次 DFT）
- 倍率：要分辨颗粒内的浓度梯度（SPMe 分辨不了，得用 DFN）
- SEI：要把界面动力学和输运耦合起来的老化模型

要算什么指标，就规定了用什么模型。这是物理判断，不是预算判断。

### 3. 有些指标能事先算出最好的情况，有些不能

```
由材料常数给出 ←────────────────────────────────→ 没有可用理论
平台电压   倍率    析锂    T_max    热失控     SEI      循环寿命
(材料)    (扩散)  (传质)  (能量)   (拟合)   (界面)    (机理分摊)
   └──── 体相：有成熟理论 ────┘   └── 界面：还没有 ──┘
                                          ↑
                              还有一类"算不出"不在这里：
                              从设定的量到仿真参数，隔着工艺
```

"算不出"有两种原因，补救方式完全不同：

| | 原因 | 例子 | 能不能补 |
|---|---|---|---|
| **还没有理论** | 科学上还没有可用的预测理论 | SEI 动力学、包覆效果、添加剂作用 | 要等科学进展 |
| **隔着工艺过程** | 从设计上设定的量，到仿真参数，中间有一段既控制不了也算不出的过程 | 碳网络电导率、粘结剂分布 | **原则上可补**——测微结构（FIB-SEM / X 射线断层）后做微结构分辨仿真 |

**实例：碳/粘结剂配比为什么算不出电导率**

参数集里有电极电子电导率（是一个输入的数），但没有碳/粘结剂比例——缺的正是这个映射：

$$(\text{碳比例},\ \text{粘结剂比例},\ \text{粒径},\ \text{混合})\ \longrightarrow\ \sigma_{\text{电极}}$$

难在哪：**配方不决定性质，配方加工艺才决定**。

```
配方 → 浆料 → 涂布 → 干燥 → 辊压 → 微结构 → 有效电导率
        ↑       ↑       ↑       ↑         ↑
      分散    厚度  粘结剂迁移  压实   碳网络连通性
```

- **分散**：炭黑先聚成一次颗粒（~30–50 nm），再团聚成次级结构；同样的重量分数，不同牌号（DBP 吸油值不同）电导率能差几个数量级
- **干燥**：粘结剂随溶剂前沿迁移、在表面富集——取决于干燥温度与速率
- **辊压**：压实重排碳网络，还可能压裂颗粒

渗流理论给出 $\sigma \propto (\varphi-\varphi_c)^t$ 的形式，但 $\varphi_c$ 不是体积分数，而是连通碳网络的有效体积分数；而极片恰恰设计在渗流阈值附近——那正是这个关系最不准的区域。

### 4. 一个设计变量能不能用，看从设定值到仿真参数隔了几步

> **一个设计变量能用，前提是：从设计上设定的那个量，到仿真里的参数，中间没有隔着一段既控制不了、也算不出来的过程。**

**判据**：你设的那个量，仿真器（电芯级是 **PyBaMM**）的参数表里有没有同名的一格？值能不能直接填进去？

三种情况：

| 情况 | 特征 | 后果 |
|---|---|---|
| **通** | 设定值与仿真参数同名 | 能设计，也能验证 |
| **断在半路** | 参数表里有这一格，但没有从设定值走到它的路 | 能设，但设了不知道后果 |
| **没有这一格** | 模型里不存在这个概念 | 设了也读不懂 |

**逐个设计变量过一遍**（步骤编号同第二节）。**传导链**列写出从"你手能拧的旋钮"到"最终指标"的完整路径；**△** = 这里补得起来（要花代价），**✗** = 这里补不起来。

| 步骤 | 设计变量 | 传导链 | 情况 |
|---|---|---|---|
| **2 选化学体系** | 换已验证体系 | 体系 → **PyBaMM**（整套参数拿来即用）→ 能量密度、倍率、析锂、$T_{\max}$、SEI | 通 |
| | 新组分 | 化学式 → **CHGNet / QE** → 平均电压、形成能 → **✗ 断**（推不出整套参数）→ 电芯性能 | ✗ 缺输入 |
| **3 电极配方与修饰** | 负载量 | 负载量 → 质量（代数）＋ **一次 1C 放电** → 能量密度 | 通 |
| | 颗粒半径分布 | 半径 → **PyBaMM** → 倍率 | 通 |
| | 导电剂 / 粘结剂比例 | 比例 → **✗ 断**（要成像拿三维微结构）→ 电极电子电导率 → PyBaMM → 内阻、倍率 | ✗ 缺输入 |
| | 包覆 / 掺杂剂 | 包覆材料 → **△ 贵**（DFT 算界面迁移势垒）→ SEI 速率常数 → PyBaMM → SEI 厚度 | △ 算得慢 |
| **4 电芯结构** | 电极厚度、孔隙率、N/P、隔膜、集流体 | → **PyBaMM** → 能量密度、析锂、倍率 | 通 |
| | 外形（圆柱 / 软包 / 叠片） | 外形 → **✗ 无**（PyBaMM 是一维层状模型） | ✗ 没有这一格 |
| **5 热管理** | 电芯尺寸（电极面积、冷却表面积） | 尺寸 → **PyBaMM**（集总热）→ $T_{\max}$ | 通 |
| | 冷却设计 → 散热系数 $h$ | 冷却板几何、流道、流速 → **△ 缺工具**（传热 / 流场仿真）→ $h$ → PyBaMM → $T_{\max}$ | △ 缺模型 |
| **6 电解液配方** | 盐浓度、溶剂比 | 配方 → **MD** → $\sigma$、$t^+$、$D_e$ → **PyBaMM** → 倍率、低温保持 | 通 |
| | 添加剂 | 分子 → **xTB** → HOMO / LUMO → **✗ 断**（到 SEI 速率常数没有换算）→ SEI 厚度 | ✗ 缺理论 |
| **7 工艺** | 化成、注液 | → **✗ 无**（PyBaMM 里没有这两个量） | ✗ 没有这一格 |

**链上的断点分五种。关键不在"现在断了"，而在"补不补得起来"**——所以标记分两类：**△ 补得起来（花代价），✗ 补不起来。**

| 标记 | 类型 | 缺什么 | 代理模型帮得上吗 | 怎么补 | 表里的例子 |
|---|---|---|---|---|---|
| **△** | 算得慢 | 算力 | **帮得上** | 建代理模型——用便宜的近似贵的 | 包覆剂 → SEI 速率常数 |
| **△** | 缺模型 | 另一套仿真工具 | 帮得上（先有工具，才谈代理） | 建传热 / 流场仿真 | 冷却设计 → 散热系数 |
| **✗** | 缺输入 | 实验数据 | 帮不上 | 先做实验拿数据 | 导电剂比例 → 电导率；新组分 → 整套参数 |
| **✗** | 缺理论 | 科学本身 | 帮不上 | 等科学进展 | 添加剂 → SEI 厚度 |
| **✗** | 没有这一格 | 模型里没这一维 | 帮不上 | 换成能表示它的模型（二维 / 三维几何、化成模型） | 外形、化成与注液 |

**△ 那一类是"能修的"**：真值算得出来，只是贵，所以可以拿便宜的近似它。**✗ 那三类修不了**——缺输入要实验、缺理论要等科学、没有这一格要换模型，都不是建个代理模型能解决的。

**这也说明代理模型是个能力边界，不是万能药**：它省的是计算时间，不是计算能力，需要一个哪怕很慢的真值来源。

**散热系数为什么不在"通"那一栏**：它不是一个可以自由设的设计量，而是**整个冷却系统的结果**（冷却方式、板的位置、接触热阻、流速、表面积 / 体积比……）。直接设它就等于**假设存在一个能给出该 $h$ 的冷却系统**，而那个系统没有被验证过。这与"把没有依据的参数值当设计自由"是同一类动作。

**归总**：

| | 变量 |
|---|---|
| **能设计又能验证** | 换已验证体系、负载量、颗粒半径分布、厚度 / 孔隙率 / N/P / 隔膜 / 集流体、电芯尺寸、盐浓度与溶剂比 |
| **△ 补得起来** | 包覆 / 掺杂剂（建代理模型）；冷却设计 → 散热系数（建传热 / 流场仿真） |
| **✗ 补不起来——要实验** | 导电剂 / 粘结剂比例、新组分 |
| **✗ 补不起来——要等科学** | 添加剂 |
| **✗ 补不起来——要换模型** | 外形、化成制度与注液量 |

这张表决定了 agent 的实际设计空间：**它不是"六个步骤都能做"，而是六大块里有一半只能设、不能验。** 一个设计量如果设了却拿不到反馈，它不会让结果变好，只会让报告多一行字。

## 六、仿真能支持到哪一步

| 步骤 | 能算出什么 | 卡在哪 |
|---|---|---|
| **1 定场景与指标** | 不适用 | 是输入，不是 agent 的决定 |
| **2 选化学体系** | **已参数化的体系** | 新组分能算晶体 / 分子性质，算不了电芯性能 |
| **3 电极配方与修饰** | **颗粒尺寸** | 碳 / 粘结剂配比算不了（隔三步）；包覆剂只筛已有，不做分子设计 |
| **4 电芯结构** | **厚度、孔隙率、N/P、隔膜、集流体** | 外形（圆柱 / 软包 / 叠片）与工艺窗口（最薄隔膜、最厚涂布）不在里面 |
| **5 热管理** | **电芯尺寸** | 冷却设计到散热系数 $h$ 要传热 / 流场仿真，我们没有；$h$ 不是一个能自由设的设计量 |
| **6 电解液配方** | **输运参数（$\sigma$、$t^+$、$D_e$）** | 添加剂功能算不了（分子性质到 SEI 质量还没验证）；只筛已有 |
| **7 工艺** | **无** | 化成制度、注液量没有对应的仿真参数（压实就是第 4 步的孔隙率） |

两条直接后果：

**一、分层不该按物理对象分，该按"从设定值到仿真参数隔了几步"分。** 按化学 / 配方 / 结构 / 热分，是按对象分；按隔几步分，才对应"能不能判定"。

**二、算不了的地方要如实说。** 第 7 步给不出任何东西；设计系统应当说"这一步需要工艺数据，仿真给不了"，而不是编一套看起来合理的化成制度。这是最容易验证的行为准则。
