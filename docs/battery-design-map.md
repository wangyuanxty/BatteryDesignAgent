# 电池设计：指标、步骤、仿真与对应关系

本文整理电池电芯设计的领域结构，用于架构设计与任务划分。四部分：性能指标、设计步骤、仿真方法、对应关系。最后给出四条观察。

一项指标最好能做到多少、能不能事先算出来，分三种情况，原因完全不同：

- **能算**：由物理或材料常数给出，不随设计变化，可以据此判定"够不够得着"
- **不能算——没有可用的理论**：只有经验关系（如界面化学）
- **不能算——隔着工艺**：从设定的量到仿真参数，中间有一段既控制不了也算不出的过程（如工艺造成的微结构）

## 二、设计步骤

按实际设计流程的顺序。

| # | 步骤 | 主要变量 |
|---|---|---|
| 1 | **定场景与指标** | 应用场景决定哪些指标是硬约束 |
| 2 | **选化学体系** | 正极（NMC / LFP / LMO）、负极（石墨 / Si / SiOx / 锂金属）、电解液大类 |
| 3 | **定电极配方与修饰** | 活性物质 / 导电剂 / 粘结剂比例、颗粒半径分布；包覆 / 掺杂（作用在界面，改 SEI 动力学或开裂速率） |
| 4 | **定电芯结构** | 电极厚度、孔隙率、N/P 比、隔膜、集流体、电芯外形（软包 / 圆柱 / 叠片） |
| 5 | **定热管理** | 冷却设计（冷却板、流道、流速）、电芯尺寸 |
| 6 | **定电解液配方** | 溶剂比、盐（LiPF₆ / LiFSI）、添加剂（成膜 / 阻燃 / 过充保护） |
| 7 | **定工艺** | 化成制度、注液量、压实 |

### 第 2 步与其余几步的关系

**第 2 步不是并列的第 2 步——它是 3–6 的容器，也是它们的边界。**

**一、包含**：体系的参数集里**已经含有** 3/4/5/6 涉及的所有量——正负极（3、4）、电解液（6）、隔膜与集流体（4）、几何（4）、热（5）。所以步骤 2 选的是"**用哪一套**"，3–6 是在这套上把某些数**覆盖掉**：

```
步骤 2  选一套参数集（内置 15 个里选 1）
          ↓ 决定：材料是什么、哪些参数可以改
   ├── 步骤 3  电极配方与修饰
   ├── 步骤 4  电芯结构
   ├── 步骤 5  热管理
   └── 步骤 6  电解液配方
```

**二、决定能力**：参数集里**有没有那个参数，决定 3–6 能不能做**。

| 步骤 2 选的体系 | 3–6 能做什么 |
|---|---|
| 带 SEI 参数的（Chen2020 / OKane2022 等） | 能做 SEI 判据、能跑老化 |
| **不带 SEI 的（ORegan2022 / Prada2013）** | **做不了** SEI 判据 |
| 带开裂参数的（OKane2022 / Ai2020） | 能算开裂 |

**三、成本不对称，所以顺序也是定死的**

| | 步骤 2 换体系 | 步骤 3–6 改参数 |
|---|---|---|
| 代价 | **贵**——整套参数换掉，下游全变 | **便宜**——覆盖几个数 |
| 空间 | **离散**，15 个左右 | **连续** |
| 风险 | 可能换到做不了该判据的体系 | 基本无 |

所以顺序是：**先算上限（当前体系够不够得着），够不着才动步骤 2；够得着就只在 3–6 里调。**

**三处例外**——这几处的上游在参数集之外：

| 位置 | 为什么 |
|---|---|
| 步骤 3 的导电剂 / 粘结剂比例、包覆剂 | 参数集里没有对应参数（只有电导率、SEI 速率常数） |
| 步骤 5 的散热系数 $h$ | 是冷却系统的结果，不是参数集里的自由值 |
| 步骤 6 的添加剂 | 同上，只有 SEI 速率常数，从分子到它没有路 |

**尽管是容器关系，第 2 步与第 6 步仍是两条不同的路**：化学体系决定**能量上限**，电解液配方决定**界面行为**，两者影响的指标几乎不重叠。

### 关于"选"与"造"的边界

本图覆盖的是**从已有里选**：化学体系从已验证的参数集里选，添加剂与包覆/掺杂材料从已有化合物目录里选。

**不覆盖"设计新分子并合成"那一段**，两个原因：

| 原因 | 说明 |
|---|---|
| **仿真给不出功能** | 分子性质（还原电位、HOMO/LUMO、结合能）能算，但从性质到电池性能（SEI 质量、界面动力学 $k$）这条链接没有理论，只能靠经验关系 |
| **合成与实测在边界外** | 设计出的分子要合成、要实测才作数，两步都需要湿实验；周期以年计，与仿真循环差几个数量级 |

**这不是取舍，是领域本身的分工**：新分子通常由化工 / 材料公司设计合成，电解液厂商配成电解液，电池厂做的是**选型、配方与结构**。本图覆盖的正是后一段。

## 三、仿真方法

按物理尺度排列。

| 尺度 | 方法 | 算什么 | 代价 |
|---|---|---|---|
| 分子 | DFT（ORCA / CP2K） | 轨道能级、氧化还原电位、反应路径 | 小时–天 |
| | 半经验（xTB） | HOMO / LUMO 快速估计 | 秒 |
| | MD | 扩散系数、电导率、迁移数、溶剂化结构 | 小时 |
| 晶体 | 周期 DFT（QE） | 晶格常数、形成能、**OCP 电压平台** | 小时 |
| | ML 势（MACE / CHGNet） | 结构弛豫、稳定性排序 | 毫秒–秒 |
| 电极 | SPM / SPMe | 固相扩散、简化极化 | 秒 |
| | P2D / DFN | 全阶、空间分辨 | 分钟 |
| | DFN + 老化 | SEI 生长、颗粒开裂、容量衰减 | 分钟 |
| 电芯 | DFN + 热耦合 | 温度分布、$T_{\max}$ | 分钟 |
| | 热失控 ODE | 触发判据 | 秒 |
| | 机械–热耦合 | 针刺 / 挤压 | 分钟–小时 |
| 系统 | CFD | 电池包级热管理 | 小时 |

**电极与电芯两行由 PyBaMM 提供**（SPM / SPMe / P2D / DFN、老化、热耦合都在里面）；分子与晶体两行由 xTB / DFT / MD / ML 势提供。**下面说的"仿真器"、参数表，指的就是这两组里的对应工具。**

**特征时间**（典型数量级，实际值须按所选参数集计算）：

- 固相扩散：$\tau_s = R^2/D_s \sim$ 10³ s（$R=5\,\mu$m，$D_s=10^{-14}$ m²/s）
- 电解液输运：$\tau_e = L^2/D_e^{\rm eff} \sim$ 10² s（$L=100\,\mu$m，$D_e^{\rm eff}\sim3\times10^{-11}$ m²/s）

两者与 1C 放电（3600 s）同量级，这是倍率性能受扩散限制的直接原因。

## 四、对应关系

### 指标由什么决定

| 指标 | 由哪一层决定 | 用什么仿真 | 最好能到多少，依据是什么 |
|---|---|---|---|
| **比能量 Wh/kg** | 化学体系 × 结构 | 分母（质量）纯代数；分子要**一次 1C 放电**（秒级） | 材料常数给出（理论容量 × 电压），但松 |
| **能量密度 Wh/L** | 同上 | 同上 | 材料常数给出，松 |
| **平均 / 平台电压** | 正极材料 | 周期 DFT，或参数集 OCP 数据 | 材料本身，就是那个数 |
| **比容量** | 材料理论值 × 利用率 | DFN | 上限由材料给出；利用率靠设计 |
| **倍率保持** | 固相扩散 ＋ 电解液输运 | **DFN**（SPMe 在 5C 严重低估容量） | 球扩散利用率有解析式，可用 |
| **低温保持** | 电解液电导率的温度依赖、界面阻抗 | DFN（带温度依赖参数） | Arrhenius 关系，参数集内可用 |
| **DCR / 比功率** | 厚度、孔隙率、电导率 | 从放电起始压降算 | 只有量级，不紧 |
| **循环寿命** | SEI 生长、开裂、锂库存损失 | DFN + 老化模型 | 各机理贡献怎么分摊，没有第一性原理 |
| **SEI 厚度** | 界面动力学 $k$、温度、时间 | 老化模型 | 包覆能把 $k$ 压到多少，算不出来 |
| **析锂** | 负极电位 ＝ 平衡电位 ＋ 过电位 | DFN，读 $\phi_a(t)$ 时序 | 传质极限电流给出 |
| **$T_{\max}$** | 产热（I²R ＋ 熵热）vs 散热 $hA$ | 电化学–热耦合 | 能量守恒给出 |
| **热失控触发** | 放热反应动力学、散热、尺寸 | 三副反应 ODE / Semenov | 判据形式是经典的；数值靠 ARC 拟合 |
| **针刺通过性** | 同上 ＋ 机械侵入 | 机械–热耦合 | 同上 |
| **N/P 比** | 纯设计选择 | 不用仿真 | 是约束，不是指标 |

### 指标不达标时往哪走

**指标与步骤是多对多，先查这个指标能被哪几步改**（步骤编号同第二节）：

| 指标 | 哪几步能改它 |
|---|---|
| **能量密度**（质量 / 体积）、比容量 | 2 化学体系 · 3 电极配方 · 4 电芯结构 |
| **倍率保持** | 2 化学体系 · 3 电极配方 · 4 电芯结构 · 6 电解液 |
| **低温保持** | 3 电极配方 · 6 电解液 |
| **析锂** | 3 电极配方 · 4 电芯结构 · 6 电解液 |
| **SEI 厚度**、循环寿命 | 3 电极修饰 · 6 电解液 |
| **$T_{\max}$** | 4 电芯结构 · 5 热管理 |
| **热失控 / 针刺** | 2 化学体系 · 4 电芯结构 · 5 热管理 |
| **电压平台** | **只有 2 化学体系** |

因为多对多，所以写不成"第 N 步 → 对应指标"。

**拿到候选步骤之后，第一步不是动手改，是先问：当前体系最多能做到多少，够得着要求吗？**

够不着 → 直接换体系，别在结构上浪费时间。够得着 → 才按成本从低到高调。

| 指标 | 上限算得出来吗 | 够不着 → | 够得着 → |
|---|---|---|---|
| **电压平台** | 有——就是材料 OCP | **换体系（第 2 步）**，没有别的路 | —— |
| **能量密度** | 有——理论容量 × 电压 | **换体系（第 2 步）** | 结构（第 4 步）→ 配方（第 3 步） |
| **倍率 / 低温** | 有——扩散时间极限 | 换体系（第 2 步）或电解液（第 6 步） | 结构（第 4 步）→ 配方（第 3 步） |
| **析锂** | 有——传质极限电流 | 换体系（第 2 步）或电解液（第 6 步） | 结构（第 4 步）→ 配方（第 3 步） |
| **$T_{\max}$** | 有——能量守恒（这个界松） | 换体系（选产热更低的化学） | 热管理（第 5 步）→ 结构（第 4 步） |
| **SEI 厚度** | **没有** | —— | 电极修饰（第 3 步）· 电解液（第 6 步） |

三件事一眼可见：

**一、电压平台最干脆**——上限就是材料本身，够不着只能换体系，没有第二条路。
**二、SEI 是唯一算不出上限的指标**——所以它是唯一"只能试"的，与第五节第 3 条是同一件事（算得出上限的都在体相物理，算不出的都在界面化学）。
**三、上限够得着时，才轮到成本顺序**——结构最便宜（只是改数），配方与修饰要换材料，电解液要跑 MD。

**这个顺序不能写死**：要是按"先榨结构，再换体系"办，那么在**要求已超过当前材料上限**的指标上（电压平台超过正极 OCP、能量密度超过理论容量 × 电压所能给的），会在结构上白折腾一轮——必须**先算上限，再决定动手顺序**。

## 五、四条观察

### 1. 能量密度要一次仿真，只有质量和 N/P 比是纯代数

$$E = \frac{\int_0^{t_d} V(t)\,I\,dt}{\sum_i l_i(1-\varepsilon_i)\rho_i A}$$

| | 怎么来 |
|---|---|
| **分母**（质量）＝ 层厚 × 密度 × 面积 | 纯代数——设计变量与材料常数的直接组合 |
| **分子**（放电能量）＝ $\int V(t)I\,dt$ | **要电压曲线 → 要一次 1C 放电仿真**（秒级） |

所以能量密度比老化、析锂那些便宜得多，但**不是"完全不用仿真"**。可以用"理论容量 × 平均电压"估一个上界——那是纯代数，但**是上界，不是实际值**。

**真正纯代数的只有质量、N/P 比这类**（层厚 × 密度、容量比），它们不是微分方程的解。

### 2. 用什么模型，由要算什么指标决定

- 平台电压：只需要一个静态 OCP 值（一次 DFT）
- 倍率：要分辨颗粒内的浓度梯度（SPMe 分辨不了，得用 DFN）
- SEI：要把界面动力学和输运耦合起来的老化模型

要算什么指标，就规定了用什么模型。这是物理判断，不是预算判断。

### 3. 有些指标能事先算出最好的情况，有些不能

```
由材料常数给出 ←────────────────────────────────→ 没有可用理论
平台电压   倍率    析锂    T_max    热失控     SEI      循环寿命
(材料)    (扩散)  (传质)  (能量)   (拟合)   (界面)    (机理分摊)
   └──── 体相：有成熟理论 ────┘   └── 界面：还没有 ──┘
                                          ↑
                              还有一类"算不出"不在这里：
                              从设定的量到仿真参数，隔着工艺
```

"算不出"有两种原因，补救方式完全不同：

| | 原因 | 例子 | 能不能补 |
|---|---|---|---|
| **还没有理论** | 科学上还没有可用的预测理论 | SEI 动力学、包覆效果、添加剂作用 | 要等科学进展 |
| **隔着工艺过程** | 从设计上设定的量，到仿真参数，中间有一段既控制不了也算不出的过程 | 碳网络电导率、粘结剂分布 | **原则上可补**——测微结构（FIB-SEM / X 射线断层）后做微结构分辨仿真 |

**实例：碳/粘结剂配比为什么算不出电导率**

参数集里有电极电子电导率（是一个输入的数），但没有碳/粘结剂比例——缺的正是这个映射：

$$(\text{碳比例},\ \text{粘结剂比例},\ \text{粒径},\ \text{混合})\ \longrightarrow\ \sigma_{\text{电极}}$$

难在哪：**配方不决定性质，配方加工艺才决定**。

```
配方 → 浆料 → 涂布 → 干燥 → 辊压 → 微结构 → 有效电导率
        ↑       ↑       ↑       ↑         ↑
      分散    厚度  粘结剂迁移  压实   碳网络连通性
```

- **分散**：炭黑先聚成一次颗粒（~30–50 nm），再团聚成次级结构；同样的重量分数，不同牌号（DBP 吸油值不同）电导率能差几个数量级
- **干燥**：粘结剂随溶剂前沿迁移、在表面富集——取决于干燥温度与速率
- **辊压**：压实重排碳网络，还可能压裂颗粒

渗流理论给出 $\sigma \propto (\varphi-\varphi_c)^t$ 的形式，但 $\varphi_c$ 不是体积分数，而是连通碳网络的有效体积分数；而极片恰恰设计在渗流阈值附近——那正是这个关系最不准的区域。

### 4. 哪些量能当设计变量：两头都要对得上

> **一个量能当设计变量，前提是两头都对得上：**
> **① 下行——从你设定的量，能走到仿真参数；**
> **② 上行——从仿真参数，能说回一个做得出来的材料或工艺。**
> **一头断了，它就不能算设计变量。**

**这条判据划定的就是设计空间**：进不了设计空间的量，agent 设了也是白设——要么仿真里那个数不动，要么那个数对应不了实物。

**下行**：你设的那个量，仿真器（电芯级是 **PyBaMM**）的参数表里有没有同名的参数？值能不能直接填进去？

**上行**：反过来，这个参数值对应一个说得出的材料或工艺吗？改它等于选了什么？

两类断法，后果不一样：

| 断的方向 | 例子 | 后果 |
|---|---|---|
| **下行断**（设了推不出参数） | 导电剂 3% → 电极电子电导率 | **改了等于没改**——仿真里那个数不动，算出来的内阻与倍率一模一样 |
| **上行断**（参数对应不了实物） | $D_s = 10^{-13}$ → 哪个材料？ | 那不是设计，是**假设存在一种你不知道是什么的材料** |

三种情况（按下行分）：

| 情况 | 特征 | 后果 |
|---|---|---|
| **通** | 设定值与仿真参数同名 | 能设计，也能验证 |
| **断在半路** | 参数表里有这一项，但没有从设定值走到它的路 | 能设，但设了不知道后果 |
| **模型里没有这一项** | 模型里不存在这个概念 | 设了也读不懂 |

**"设计变量"和"仿真参数"是什么关系**

不是一回事，但大部分重叠：

```
参数集里的参数（Chen2020 有 93 个）
├── 材料身份（OCP 曲线、D_s、理论容量、交换电流密度…）
│      ← 随体系走，不能单独设
└── 可覆盖的值（厚度、孔隙率、颗粒半径、盐浓度、集流体…）
       ← 这些才是设计变量

你手能拧的旋钮
├── 在参数集里、同名       → 通（设计变量就是那个参数）
├── 在参数集里、不同名     → 断（参数在，但从设定值走不到它）
└── 不在参数集里           → 断（模型里没有这一项）

另有一个不同类的动作：
体系选择 —— 在内置的参数集里选 1（换整套，不是改一个数）
```

**"不同名"为什么是断**：参数表里**有**那一项，但它**不是从你设的量算出来的**。以导电剂比例为例：

| | |
|---|---|
| 你设的 | 导电剂 3%、粘结剂 2%（重量分数） |
| 仿真要的 | `Positive electrode conductivity [S.m-1]` = 0.18 |
| 参数集里有这一项吗 | **有** |
| 能从 3% 走到 0.18 吗 | **不能**——中间隔着浆料 → 干燥 → 辊压 |

**后果是"改了等于没改"**：把导电剂从 3% 改到 6%，仿真里的电导率还是 0.18，算出来的内阻与倍率**一模一样**——除非你另外知道 6% 对应多少，而那个数没有地方查、也算不出。

包覆剂、添加剂是同一个形状：目标参数（`SEI kinetic rate constant`）**在参数集里**，但从"材料"或"分子"**走不到它**。

**三类动作不同类，只是并列在同一张表里**：选体系（换整套，离散）、覆盖参数（改一个数，连续）、设一个不在集里的量（会断）。

**为什么不能直接拿参数表里的参数当设计变量**

因为"**参数表里能改**"和"**设计上能设**"不是一回事——两头都要对得上：

| 参数 | 两头 | 是设计变量吗 |
|---|---|---|
| 电极厚度 | 涂布间隙 ↔ 同名参数 | **是** |
| 孔隙率 | 辊压设定 ↔ 同名参数 | **是** |
| 颗粒半径 | 粉体规格 ↔ 同名参数 | 是（可选规格有限） |
| 盐浓度、溶剂比 | 称量配液 ↔ 输运参数（要过 MD） | 是，但贵 |
| **$D_s$、OCP、理论容量** | 参数有，**但说不出哪个材料给出它** | **不是**——改它等于假设存在一种你不知道是什么的材料 |
| 导电剂 / 粘结剂比例 | 设定值有，**但推不出参数** | **不是** |

这就是"参数集里九十多个参数只有一部分是设计变量"的原因：不是"能不能改那个数"，而是**改了之后有没有对应的实物**。

同一条原则在既有论文里也写过：*a sixth family (solid-phase conductivity and diffusivity) is deliberately excluded as a design variable because no formulation model maps them, so any adjustment would be an unverifiable estimate*。

**逐个设计变量过一遍**（步骤编号同第二节）。**参数**列写 PyBaMM 里对应的参数名——**一个设计变量一行，不合并**；**△** = 补得起来（花代价），**✗** = 补不起来。

**另有一个不属七步、但改几何时必须同步的量**

| 量 | 参数 | 为什么 |
|---|---|---|
| **额定容量** | `Nominal cell capacity [A.h]` | 它定义了"1C 是多少安培"。实测：两面厚度同时加倍，实际容量 4.939 → 9.974 Ah，**而这个参数一直是 5.000 Ah 不变**。所以 **改几何后不同步更新它，1C 就不再是 1C**，所有按 C 率定义的工况全部失真。它**不是可自由设的设计量，而是必须与几何保持一致的量**。 |

**不是设计变量的参数**（列在此处以免再漏）：材料身份（两侧 OCP 曲线、颗粒扩散系数、电极电子电导率、最大锂浓度、交换电流密度、电荷转移系数、双电层电容、Bruggeman 系数、各层密度/比热/热导率…）、运行工况（环境温度、初始温度、电流、电压上/下限）。它们随体系走，或由使用条件给定。

**注：表里按变量给的是汇总，决定成败的是某一跳——逐行拆开**

**（2）选化学体系**

| 跳 | 处境 |
|---|---|
| 换已验证体系 → PyBaMM | **通**——但可选的只有几个已参数化体系（Chen2020 / ORegan2022 / OKane2022 / Prada2013 等），是个**离散小集合**，不是连续空间 |
| 化学式 → 理论容量、平均电压 | **通**——理论容量按化学式算，平均电压 CHGNet / QE 秒级 |
| 化学式 → OCP 曲线、$D_s$ | **△ 算得慢**——OCP 要 DFT 算十几个锂化态；$D_s$ 要 MD / NEB |
| 化学式 → 动力学、SEI 速率常数 | **✗ 缺理论**——没有第一性原理路径 |
| → 整套参数齐备 | **✗ 缺输入**——没有覆盖任意新组分的参数库，也没人测过这个材料 |

**体系是什么、从哪来**

体系 = **一整套电芯材料方案**；换体系 = 换一整颗电芯用什么做，不是只换正极。一套参数里包含：

| 部分 | 里面是什么 |
|---|---|
| 正极 / 负极 | 活性材料体积分数、OCP 曲线、颗粒半径、固相扩散系数、电子电导率、比容量 |
| 电解液 | 盐、溶剂、初始浓度、扩散系数、电导率、迁移数 |
| 隔膜 | 厚度、孔隙率、Bruggeman 系数 |
| 集流体 | 厚度、电导率、热导率 |
| 几何 | 电极高度、宽度、各层厚度 |
| 热 | 各层热导率、比热容、散热表面积 |
| 老化（若带） | SEI 动力学、溶剂扩散系数、开裂速率、锂库存损失 |

**来源**：PyBaMM 是**收集者与打包者**，不是数据生产者——每个参数集对应一篇实测标定的论文（名字就是"第一作者 + 年份"）。我们 bib 里已核实四条：Chen2020、ORegan2022、OKane2022、Prada2013。

**PyBaMM 内置 15 个锂离子参数集，覆盖范围差别很大**：

| 参数集 | 参数数 | SEI | 开裂 |
|---|---|---|---|
| OKane2022 | 131 | 有 | 有 |
| Ai2020 | 126 | 有 | 有 |
| Ecker2015 / Mohtat2020 | 108 | 有 | — |
| Marquis2019 | 104 | 有 | — |
| NCA\_Kim2011 | 103 | 有 | — |
| Ramadass2004 | 98 | 有 | — |
| Chen2020 | 93 | 有 | — |
| **ORegan2022** | 76 | **—** | — |
| Xu2019 | 65 | 有 | — |
| **Prada2013** | 53 | **—** | — |

（另有 Chen2020\_composite、Ecker2015\_graphite\_halfcell、OKane2022\_graphite\_SiOx\_halfcell、MSMR\_example\_set 等变体。）

**两条直接后果**：

**一、换体系是离散的**——十五个左右，不是连续空间。
**二、还被指标限制**——要出 SEI 判据就只能在带 SEI 的集里选；ORegan2022 与 Prada2013 出不了。

**为什么说"没有地方查"**：

| 现有的库 | 有什么 | 为什么不够 |
|---|---|---|
| Materials Project / OQMD | 晶体结构、形成能、部分电子结构 | 是 **DFT 数据**，不是电池模型参数——没有 OCP 曲线、没有 $D_s$、没有动力学 |
| PyBaMM 自带参数集 | Chen2020 / ORegan2022 / OKane2022 / Prada2013 等 | 只有**几个已被参数化的体系**，不是可扩展的库 |
| 电池公开数据集（NASA / CALCE 等） | 实测循环曲线 | 是**实测数据**，不是模型参数 |
| 文献单点值 | 个别材料的电化学参数 | 零散、测法不一、不可比 |

所以对新组分只能用**常数 OCP 近似**硬搭一套参数——那只是把 OCP 曲线拉直的一个粗略近似，误差没有界：能算出个电芯数字，但那不是真值。

**（3）电极配方与修饰**

| 跳 | 处境 |
|---|---|
| 负载量 → 电极厚度 → 质量（代数）＋ 一次 1C 放电 | **通** |
| 颗粒半径 → PyBaMM | **通**——参数集里就是"正 / 负极颗粒半径"这一个数 |
| 粒径**分布** → 模型 | **△**——PyBaMM 有分布参数（对数正态，均值取半径、标准差默认 0.3）和模型侧的 `distribution` 开关，但**分布形状是假设的**；真实分布要激光粒度仪测 |
| 导电剂 / 粘结剂比例 → 电极电子电导率 | **✗ 缺输入**（改配方时；不改配方就用参数集自带的值） |
| 包覆材料 → 界面迁移势垒 | **△ 贵**——要建 DFT 界面模型 |
| 界面迁移势垒 → SEI 速率常数 | **△**——有 Arrhenius 关系，但**要先假设是哪种机理**（离子输运还是电子隧穿），不同假设给的 $k$ 差很多 |
| SEI 速率常数 → PyBaMM | **通**——参数集里有"SEI kinetic rate constant"这一项 |

**导电剂 / 粘结剂比例那一跳，只在改配方时才断**：

| 这一跳 | 处境 |
|---|---|
| 不改配方（用参数集自带的电极电子电导率） | **通**——参数集里有一个标定过的值 |
| 改配方 → 新的电导率 | **✗ 缺输入**——要么做极片实测（四探针），要么成像（X 射线断层 / FIB-SEM）拿到三维碳网络 |
| 三维微结构 → 电导率 | **通**——在网格上解电导方程是标准做法；卡的不是算法，是拿不到结构 |
| 查文献 | 有零散实测值，但测法不一、压实不同，无法外推到新配方 |

**生成式微结构也救不了**：可以用球堆积 / 相场造出虚拟电极结构，但造得对不对取决于能否模拟浆料 → 干燥 → 辊压——而那正是缺的那一段。**只是换了个缺的东西，还是缺。**

**渗流理论给的是形式不是值**：$\sigma \propto (\varphi-\varphi_c)^t$，但 $\varphi_c$ 是连通碳网络的有效体积分数，要拟合；而极片恰好设计在渗流阈值附近，那里这个关系最不准。

**（4）电芯结构 ·（5）热管理**

| 跳 | 处境 |
|---|---|
| 电极厚度、孔隙率、N/P、隔膜、集流体 → PyBaMM | **通**——都是同名参数 |
| 外形（圆柱 / 软包 / 叠片）→ 模型 | **通（pouch）**——PyBaMM 有 `cell geometry`，pouch 配 `x-lumped` 实测跑通；圆柱与 2D/3D 要补参数（极耳坐标、集流体表面积），参数集里没有 |
| 电芯尺寸 → PyBaMM | **通**——"Cell volume"、"Cell cooling surface area" 都是参数 |
| 冷却设计 → 散热系数 $h$ | **△ 缺的是流体那一段**——PyBaMM **不解流体流动**，从流道与流速到 $h$ 要 CFD 或经验关联式；但**给定 $h$ 它能算厚度方向的温度分布**（`x-lumped` 实测跑通） |

**从冷却设计到 $h$，分三档补**

| 档 | 要什么 | 一次性投入 | 单次成本 |
|---|---|---|---|
| **只选冷却方式** | 教科书经验关联式（自然对流 5–25、强制风冷 25–250、液冷 500–10000 W/m²K） | 几行代码 | 查表，瞬间 |
| **给定流道算 $h$** | OpenFOAM / COMSOL：建几何 → 划网格 → 设边界与物性 → 求解 → 后处理 | 环境半天到一天；流程几天 | **分钟到小时级** |
| **让 agent 自主设计流道** | 先解决流道几何的参数化 | 开放问题 | —— |

**关键在单次成本**：CFD 是小时级，PyBaMM 是秒级——**差三到四个数量级**。所以 **CFD 进不了设计循环**，只能当**离线造训练数据的工具**：先跑几十次训一个代理模型，之后才快；而那几十次本身又是几天。

**第二档还有两个前提**：① 几何要能**自动生成**（否则每个新设计都要手工建模）；② 要有把产热率传进 CFD 的**耦合接口**。而且 **CFD 结果准不准取决于几何细节，尤其接触热阻**——不做实测对标的话，它给出的 $h$ 仍然是估计值，只是"经过复杂计算的估计"。

**第三档的难点不在仿真**：流道几何（蛇形？并行？几进几出？）**没有现成的参数化方式**。没有参数化就没有设计空间，也就没有 agent 能搜的东西——**这是个开放问题，不是工程量问题**。

**上表的时间是经验量级，未实测。**（待办：装一个开源 CFD 跑最小算例，把实际耗时测出来。）



**（6）电解液配方**

| 跳 | 处境 |
|---|---|
| 配方 → $\sigma$、$t^+$、$D_e$（单点值） | **△ 贵**——MD 能算，但要跑小时级，且力场精度影响大 |
| 单点值 → PyBaMM | **△**——参数集里 $\sigma$ 和 $D_e$ 是**浓度 / 温度的函数**，不是一个数；MD 给的点要拟合成函数，或假设为常数（那是额外的近似） |
| 分子 → HOMO / LUMO | **通**——xTB 秒级 |
| HOMO / LUMO → SEI 速率常数 | **✗ 缺理论**——没有换算 |

**链上的断点分六种。关键不在"现在断了"，而在"补不补得起来"**——所以标记分两类：**△ 补得起来（花代价），✗ 补不起来。**

| 标记 | 类型 | 缺什么 | 代理模型帮得上吗 | 怎么补 | 表里的例子 |
|---|---|---|---|---|---|
| **△** | 算得慢 | 算力 | **帮得上** | 建代理模型——用便宜的近似贵的 | 盐浓度、溶剂比 → 输运参数 |
| **△** | 算得慢（只通一条） | 算力，且路径只有一条 | 只能帮那一条 | 建代理模型，其余参数另想办法 | 包覆剂 → SEI 侧 8 个里只通速率常数 |
| **△** | 缺模型 | 另一套仿真工具 | 帮得上（先有工具，才谈代理） | 建流场 / 传热仿真 | 冷却设计 → 散热系数 |
| **△** | 缺参数值 | 模型有这个量，参数集没给值 | 用不上 | 查手册、实测、或自己补 | 外形（圆柱）的极耳坐标；表面辐射率 |
| **✗** | 缺输入 | 实验数据 | 帮不上 | 先做实验 | 导电剂比例、新组分、粒径分布的真实形状 |
| **✗** | 缺理论 | 科学上还没有路径 | 帮不上 | 等科学进展 | 添加剂；掺杂剂 → Paris 常数 |
| **✗** | 没有对应参数 | 模型里根本没这个量 | 帮不上 | 换成能表示它的模型 | 注液量 |

**△ 能修，✗ 修不了**——缺输入要实验、缺理论要等科学、没有对应参数要换模型，都不是建个代理模型能解决的。

**"△ 算得慢"这一栏尤其不能一概而论**：里面混着三种处境——① 真算得慢、代理能帮（盐浓度 → 输运参数）；② 算得慢但**只通一条路**（包覆剂 → 势垒 → 速率常数，同组另外 7 个 SEI 参数没有路径）；③ 根本不是算力问题（输运参数是"给单点要函数"的拟合问题、表面辐射率是"参数集没给值"、外形圆柱是"要自己补几何参数"）。

**△ 那一类是"能修的"**：真值算得出来，只是贵，所以可以拿便宜的近似它。**✗ 那三类修不了**——缺输入要实验、缺理论要等科学、模型里没有这一项要换模型，都不是建个代理模型能解决的。

**这也说明代理模型是个能力边界，不是万能药**：它省的是计算时间，不是计算能力，需要一个哪怕很慢的真值来源。

**散热系数为什么不在"通"那一栏**：它不是一个可以自由设的设计量，而是**整个冷却系统的结果**（冷却方式、板的位置、接触热阻、流速、表面积 / 体积比……）。直接设它就等于**假设存在一个能给出该 $h$ 的冷却系统**，而那个系统没有被验证过。这与"把没有依据的参数值当设计自由"是同一类动作。

**但要分清缺的是哪一段**：PyBaMM **能算**从 $h$ 到温度分布这一步（`thermal` 有 isothermal / lumped / x-lumped / x-full 四档，`dimensionality` 支持 0–3；实测 `x-lumped` 配 pouch 直接跑通）；它**不能算**的是从冷却液流道与流速到 $h$ 那一步——那要 CFD 或教科书的经验关联式。**所以缺的是流体那一段，不是整个热模型。**

**归总**：

| | 变量 |
|---|---|
| **能设计又能验证** | 换已验证体系（只有几个可选）／电极厚度（＝面负载量）／孔隙率与活性材料分数（同一自由度）／颗粒半径／隔膜厚度与孔隙率／集流体厚度／电极面积／并联电极数／N/P 比（派生）／外形（pouch）／接触电阻（值要实测）／电芯尺寸／化成（值要工艺定） |
| **△ 算得慢（代理能帮）** | 盐浓度与溶剂比（MD → 输运参数）；包覆剂 → SEI 速率常数（只通这一条） |
| **△ 缺模型** | 冷却设计 → 散热系数、分部位散热（建流场 / 传热仿真） |
| **△ 缺参数值** | 外形（圆柱）的极耳坐标与集流体表面积；表面辐射率——查手册或自己补 |
| **△ 给单点要函数** | 输运参数本身（MD 给单点，参数集要的是随浓度变的函数） |
| **✗ 补不起来——要实验** | 导电剂 / 粘结剂比例、新组分、粒径分布的真实形状 |
| **✗ 补不起来——要等科学** | 添加剂；掺杂剂 → Paris 常数这类疲劳拟合参数 |
| **✗ 补不起来——没有对应参数** | 注液量 |

这张表决定了 agent 的实际设计空间：**它不是"六个步骤都能做"，而是六大块里有一半只能设、不能验。** 一个设计量如果设了却拿不到反馈，它不会让结果变好，只会让报告多一行字。

## 六、仿真能支持到哪一步

| 步骤 | 能算出什么 | 卡在哪 |
|---|---|---|
| **1 定场景与指标** | 不适用 | 是输入，不是 agent 的决定 |
| **2 选化学体系** | **已参数化的体系** | 新组分能算晶体 / 分子性质，算不了电芯性能 |
| **3 电极配方与修饰** | **颗粒尺寸** | 碳 / 粘结剂配比算不了（隔三步）；包覆剂只筛已有，不做分子设计 |
| **4 电芯结构** | **厚度、孔隙率、N/P、隔膜、集流体** | 外形要另设 `cell geometry`（pouch 可用；圆柱与 2D/3D 要补参数）；工艺窗口（最薄隔膜、最厚涂布）不在里面 |
| **5 热管理** | **电芯尺寸**（给定 $h$ 后还能算厚度方向的温度分布） | 从冷却设计到 $h$ 要流场仿真或经验关联式，我们没有；$h$ 不是一个能自由设的设计量 |
| **6 电解液配方** | **输运参数（$\sigma$、$t^+$、$D_e$）** | 添加剂功能算不了（分子性质到 SEI 质量还没验证）；只筛已有 |
| **7 工艺** | **化成**（`Initial SEI thickness`、`Initial concentration in electrode` 等） | 注液量没有对应参数（压实就是第 4 步的孔隙率）；化成**能设成初始态**，但那个值要工艺经验定，仿真推不出来 |

两条直接后果：

**一、分层不该按物理对象分，该按"从设定值到仿真参数隔了几步"分。** 按化学 / 配方 / 结构 / 热分，是按对象分；按隔几步分，才对应"能不能判定"。

**二、算不了的地方要如实说。** 注液量给不出任何东西；化成虽然**能设**成初始 SEI 厚度与初始锂化态，但**那个值要工艺经验定，仿真推不出来**——设计系统应当如实说"这一步需要工艺数据"，而不是编一套看起来合理的化成制度。这是最容易验证的行为准则。
